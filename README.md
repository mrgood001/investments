# Калькулятор доходности облигаций

Десктоп-приложение для расчёта доходности облигаций по ISIN. Данные об облигации (номинал, купон, дата погашения) подтягиваются с MOEX ISS API — пользователю нужно ввести только цену покупки и, при необходимости, дату сделки.

## Возможности

- Расчёт по ISIN: приложение само запрашивает у MOEX номинал, размер купона, частоту выплат и дату погашения.
- Два сценария расчёта:
  - **Базовый** — покупка совершена сегодня.
  - **Нестандартный** — покупка совершена в прошлом (учитывается НКД и дата сделки).
- Расчёт чистой доходности (после налога 13%), доходности за период, годовой доходности и годовой купонной доходности.
- Комиссия брокера задаётся один раз и сохраняется локально.

## Установка

```bash
git clone <repo-url>
cd investments
python3 -m venv venv
source venv/bin/activate       # Linux/macOS
pip install -r requirements.txt
```

`tkinter` — часть стандартной библиотеки, но на Linux ставится отдельным системным пакетом:

```bash
# Debian/Ubuntu
sudo apt install python3-tk

# Fedora
sudo dnf install python3-tkinter
```

## Запуск

```bash
python3 main.py
```

## Использование

1. Введи ISIN облигации и цену покупки.
2. Если покупка совершена не сегодня — поставь галочку "Покупка совершена не сегодня" и укажи дату сделки и НКД на эту дату.
3. При первом запуске приложение спросит ставку комиссии брокера — она сохранится и не будет запрашиваться повторно.
4. Нажми "Рассчитать".

## Структура проекта

```
investments/
├── main.py                  # точка входа
├── gui/
│   ├── base_window.py       # базовое окно: тема, навигация между экранами
│   └── bond_window.py       # экран калькулятора облигаций
└── core/
    ├── calculator.py        # класс Bond — вся расчётная логика
    ├── moex_client.py       # запросы к MOEX ISS API
    ├── bond_math.py         # работа с датами и подсчёт количества купонов
    └── settings.py          # хранение ставки комиссии
```

Разделение по слоям: `gui/` не содержит расчётов, `core/` не знает про Tkinter.

## Технологии

- Python 3
- Tkinter / ttk — интерфейс
- requests — обращение к MOEX ISS API

## Известные ограничения

- НКД для нестандартного сценария вводится вручную, автоматический расчёт с MOEX не реализован.
- Приложение не учитывает облигации с переменным (плавающим) купоном.
- Определение системной темы (`light`/`dark`) — заглушка, всегда возвращает `light`.
